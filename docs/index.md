# Graffiti Tools

Open source, 3D-printable tools and accessories for graffiti and mural artists.

Browse the tool documentation, download verified STL and STEP exports from [GitHub Releases](https://github.com/tipoftheaero/graffiti-tools/releases), or modify the [Build123d source](https://github.com/tipoftheaero/graffiti-tools).

## Available designs

- [Spray Masking Shield (prototype)](tools/spray-mask.md)

**Prototype models are not automatically print-tested.** Read the compatibility and status notes before relying on them.
