# Spray Masking Shield

**Status:** Prototype; print testing not documented yet.

A 240 mm-wide curved masking shield with a tapered paint-facing edge.

| Property | Value |
|---|---|
| Maximum thickness | 1.4 mm |
| Thin edges | 0.6 mm |
| Taper distance | 5 mm |
| Left vertical edge | Untapered except bottom transition |

See the [source and printing guidance](https://github.com/tipoftheaero/graffiti-tools/tree/main/tools/spray-mask) and [download a release](https://github.com/tipoftheaero/graffiti-tools/releases).

Real product photos and verified printing parameters should be added after physical tests.
